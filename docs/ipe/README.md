# Itinerario Personal para la Empleabilidad II (IPE II)

Contains business, planning, and professional employability deliverables:
- `lean_canvas.pdf` / `lean_canvas.md`: Lean Canvas model for VulnFollowUp (e.g., SaaS solution).
- `swot_competition.md`: Competitor benchmarking ($\ge 3$ commercial solutions) and DAFO / SWOT analysis.
- `legal_structure.md`: Justification of legal company structure for commercialization.
- `budget.xlsx`: Spreadsheet detailing dedicated hours per profile, hourly rate, infrastructure/license costs, and client pricing.
- `team_management/`:
  - `work_plan.md` (Gantt schedule or Kanban board export).
  - `meeting_minutes_01.md`, `meeting_minutes_02.md`: Meeting minutes documenting team decisions.
  - `portfolios.md`: Links to team members' updated LinkedIn, GitHub, and CV portfolios.

# Sostenibilidad Aplicada al Sistema Productivo

Contains environmental, social, and economic sustainability analysis:
- `sustainability_report.pdf`: 3-5 page report covering alignment with SDGs (ODS 8, 9, 12, 16), lifecycle impact assessment, and operational resilience as business sustainability.
- `optimizations_benchmark.md`: Reproducible before-and-after measurements for at least two software optimizations (e.g., API response pagination, client-side caching, payload compression).
- `best_practices_decalogue.md`: Decalogue of 10 sustainable software development principles for future company projects.

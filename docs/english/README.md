# English Modules Documentation (Ampliación de Inglés & Inglés Profesional)

This folder hosts written and audiovisual English deliverables:
- `glossary.md`: Bilingual English-Spanish technical glossary ($\ge 30$ key terms with technical definitions).
- `executive_summary.md`: One-page executive summary targeted at a financial client's Chief Risk Officer (CRO).
- `video_script.md`: Script for the 3-5 minute team demonstration video.
- `presentation_slides.pdf`: Slides prepared for the English portion of the oral defense.
- `video_link.md`: Link or file location for the recorded team demo video.
